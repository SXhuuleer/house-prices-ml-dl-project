# House Prices — ML/DL Project

Проект по прогнозированию стоимости жилой недвижимости на датасете Kaggle **House Prices: Advanced Regression Techniques**.

Цель проекта — построить воспроизводимый ML/DL-пайплайн, сравнить различные алгоритмы регрессии, исследовать влияние предобработки, Feature Engineering, выбросов и ансамблирования на качество предсказаний.

Проект включает EDA, классическое машинное обучение, нейронную сеть на PyTorch, подбор гиперпараметров, кросс-валидацию, ансамбли и формирование Kaggle submission.

Основной код вынесен из Jupyter Notebook в Python-модули. Точка входа — `main.py`, настройки экспериментов находятся в `config.yaml`.

---

## 1. Dataset

Используется датасет соревнования Kaggle:

[House Prices: Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques)

Целевая переменная — `SalePrice`, стоимость дома.

Исходный обучающий набор содержит 1460 объектов и 79 признаков после удаления `Id` и целевой переменной.

Тестовый набор содержит 1459 объектов.

Для обучения моделей используется логарифмическое преобразование:

`y_log = log1p(SalePrice)`

После получения прогнозов выполняется обратное преобразование:

`SalePrice_prediction = expm1(prediction_log)`

Это позволяет обучать модели на логарифмической шкале, а итоговый Kaggle submission формировать в исходных денежных единицах.

### Получение данных

Файлы `train.csv` и `test.csv` не включены в Git-репозиторий.

Для запуска проекта необходимо:

1. Открыть [страницу данных соревнования](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data).
2. Скачать `train.csv` и `test.csv`.
3. Поместить их в папку `data/raw/`.

Ожидаемые пути:

- `data/raw/train.csv`
- `data/raw/test.csv`

## 5. Data Preprocessing

Для подготовки признаков применяется `ColumnTransformer` из scikit-learn.

**Числовые признаки:**

- `SimpleImputer(strategy="median")`
- `StandardScaler()`

**Категориальные признаки:**

- `SimpleImputer(strategy="most_frequent")`
- `OneHotEncoder(handle_unknown="ignore")`

Предобработка включена в `Pipeline` моделей и обучается на тренировочных данных соответствующего CV-фолда.

Это предотвращает прямую утечку информации из валидационной части при вычислении статистик импутации и масштабирования.

Признак `Id` исключается из обучения моделей. При формировании Kaggle submission исходные идентификаторы тестовых объектов сохраняются.

## 7. Evaluation

Для оценки моделей используется **5-fold KFold Cross-Validation**:

- `n_splits = 5`
- `shuffle = True`
- `random_state = 42`

### Метрики

**RMSE** — основная метрика. Рассчитывается между логарифмами истинных и предсказанных цен:

`RMSE(log1p(y_true), prediction_log)`

**MAPE** — средняя абсолютная процентная ошибка на исходной шкале стоимости.

**WAPE** — сумма абсолютных ошибок, делённая на сумму абсолютных истинных цен, выраженная в процентах.

Также рассчитывается `CV Std` — стандартное отклонение RMSE по пяти фолдам.

Предобработка выполняется отдельно внутри тренировочных фолдов.

Результаты сохраняются в CSV-файлы, включая метрики для каждого фолда.

## 8. Hyperparameter Tuning

Для подбора гиперпараметров реализован `RandomizedSearchCV`.

В конфигурации предусмотрен поиск параметров для:

- Random Forest.
- Decision Tree.
- XGBoost.
- LightGBM.

Также реализована **Nested Cross-Validation**:

- Внешняя CV используется для оценки модели.
- Внутренняя CV используется для выбора гиперпараметров.

Такой подход позволяет оценивать процедуру подбора параметров на данных, не участвовавших во внутреннем поиске.

Подбор параметров и Nested CV можно включать независимо через `config.yaml`.

Для оценки нейросети используется 5-fold CV. Предобработка обучается отдельно для каждого тренировочного фолда, после чего признаки преобразуются в тензоры PyTorch.

## 10. Feature Engineering

Исследованы две группы дополнительных признаков.

### Basic Features

- `TotalSF` — суммарная площадь этажей и подвала.
- `TotalBathrooms` — суммарное количество санузлов с учётом половинных.
- `TotalPorchSF` — суммарная площадь крылец и террас.
- `HouseAge` — возраст дома на момент продажи.
- `RemodAge` — время с последней реконструкции.

### Interaction Features

- `QualGrLivArea` — взаимодействие качества дома и жилой площади.
- `QualBsmtSF` — взаимодействие качества дома и площади подвала.
- `GarageScore` — взаимодействие вместимости и площади гаража.
- `OverallScore` — взаимодействие общего качества и состояния дома.

### Результаты

| Эксперимент | CV RMSE |
|---|---:|
| CatBoost Baseline | **0.122919** |
| CatBoost + Basic Features | 0.123061 |
| CatBoost + Interaction Features | 0.126452 |

Дополнительные признаки не улучшили основную метрику CatBoost при проверенных настройках.

Поэтому финальная модель использует исходные 79 признаков.

## 11. Outlier Analysis

В ходе EDA обнаружены два необычных объекта с очень большой жилой площадью и относительно низкой стоимостью.

Для исследования их влияния реализована функция удаления выбросов только из тренировочной части каждого CV-фолда.

Используемые условия:

- `GrLivArea > 4000`
- `SalePrice < 300000`

### Результаты

| Эксперимент | CV RMSE |
|---|---:|
| CatBoost Baseline | 0.122919 |
| CatBoost с удалением выбросов на тренировочных фолдах | **0.122402** |

Удаление выбросов немного улучшило CV RMSE.

Однако пороги были выбраны на основании предварительного анализа данных, поэтому результат рассматривается как исследовательский.

В основном финальном обучении CatBoost сохранены все тренировочные объекты.

## 12. Ensembles

Реализованы три метода ансамблирования.

### Averaging

Обычное усреднение предсказаний CatBoost, XGBoost и LightGBM.

### Weighted Averaging

Взвешенное усреднение предсказаний трёх моделей.

В проверенном эксперименте использовались веса:

- CatBoost — `0.5`
- XGBoost — `0.3`
- LightGBM — `0.2`

Эти веса являются экспериментальными, а не результатом независимой оптимизации.

### Stacking

Используются:

- CatBoost, XGBoost, LightGBM — базовые модели.
- Ridge Regression — метамодель.

Метамодель обучается на out-of-fold прогнозах базовых моделей.

Для каждой базовой модели предусмотрен отдельный Pipeline с предобработкой. Во внутренней CV Stacking предобработка обучается только на соответствующей тренировочной части.

Это исключает прямую утечку через preprocessing при формировании out-of-fold предсказаний.

Полные результаты представлены в:

Таблица объединяет результаты текущего запуска и ранее выполненных экспериментов модульного ML/DL-пайплайна.

Для обозначения происхождения результатов используется колонка `Source`:

- `current_run` — результат получен при текущем запуске `main.py`.
- `previous_run` — результат загружен из ранее сохранённых CSV-файлов модульных экспериментов.

Результаты с `previous_run` не обязательно соответствуют текущей конфигурации моделей, версиям кода или параметрам экспериментов. Поэтому сводная таблица предназначена для обзорного сравнения и не гарантирует полной сопоставимости всех запусков.

**Особенности интерпретации метрик:**

- `CV RMSE` — среднее значение RMSE по пяти валидационным фолдам на шкале `log1p(SalePrice)`.
- Средний RMSE по фолдам отличается от RMSE, рассчитанного по объединённым out-of-fold предсказаниям.
- `CV MAPE` и `CV WAPE` рассчитываются на исходной шкале цен, после обратного преобразования предсказаний.
- Сравнение нескольких моделей, гиперпараметров и вариантов Feature Engineering на одних и тех же фолдах может приводить к смещению оценки из-за выбора лучшего варианта (selection bias).

Таким образом, результат CatBoost `CV RMSE = 0.122919` является оценкой качества в использованной схеме пятифолдовой кросс-валидации, но не полностью независимой оценкой окончательно выбранной модели.

Для строгой итоговой оценки необходима отдельная тестовая выборка, не участвовавшая в выборе модели, либо nested CV, включающая процесс выбора модели и её гиперпараметров.
